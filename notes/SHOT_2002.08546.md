# Do We Really Need to Access the Source Data? Source Hypothesis Transfer for Unsupervised Domain Adaptation (SHOT)

- **arXiv**: [2002.08546](https://arxiv.org/abs/2002.08546) | **发表**: ICML 2020 | **团队**: Jian Liang 等
- **PDF**: [英文原文](../papers/pdf/SHOT_2002.08546.pdf) · [中文翻译](../papers/zh/SHOT_2002.08546_zh.pdf)
- **分类**: TTA/TTT 基础

## 一句话

「无源域适应（source-free DA）」的开山作：冻结源模型的分类头（hypothesis），只用信息最大化 + 自监督伪标签更新特征编码器，让目标域特征自己对齐到源分类头上。

## 方法

1. **冻结假设**：源分类头视为源域知识的载体，适应期间不动。
2. **信息最大化**：让目标域预测既自信（低熵）又多样（类均衡），避免塌缩到单一类。
3. **自监督伪标签**：类质心最近邻产生伪标签，迭代精化，监督编码器更新。

## 对机器人 TTT 的意义

比 TENT 更早确立「无需源数据、只动部分模块」的适应范式，其「冻结头 + 调编码器」与 PAD 相反（PAD 冻结头是动作头、调编码器同向）——两者共同印证：**把领域知识锁在冻结模块里，适应只发生在与之对齐的空间**。信息最大化的类均衡项是防塌缩的早期方案，先于 SAR 的分析。

## 局限与注意

- 面向离线批量适应（整个目标域一起适应），流式单样本场景需改造。
- 类均衡假设在机器人数据（长尾动作分布）上不成立。
