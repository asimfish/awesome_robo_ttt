# Efficient Online Reinforcement Learning Fine-Tuning Need Not Retain Offline Data (WSRL)

- **arXiv**: [2412.07762](https://arxiv.org/abs/2412.07762) | **发表**: arXiv 2024（ICLR 2025） | **团队**: Zhiyuan Zhou*, Andy Peng*, Qiyang Li, Sergey Levine, Aviral Kumar（UC Berkeley / CMU）
- **PDF**: [英文原文](../papers/pdf/WSRL_2412.07762.pdf) · [中文翻译](../papers/zh/WSRL_2412.07762_zh.pdf)
- **分类**: TTT 之前的阶段——RL 微调与平滑探索

## 一句话

在线微调不必继续在离线数据上训练：只要一开始用少量「温启动」rollout 重新校准 Q 值（Warm-Start RL），就能丢掉离线数据只用在线交互，既省算力又解除了离线约束对性能上限的钳制；并从理论上解释了丢数据即崩的原因是 Q 函数在分布切换时的「重新校准」失败。

## 方法

1. **诊断**：直接丢离线数据 → Q 值崩塌 → 策略遗忘；根因是 TD 目标分布骤变。
2. **WSRL**：先用预训练策略收集少量在线数据「预热」Q 与 replay，再纯在线训练。

## 对本仓库 / 方案的意义

对部署期 TTT 尤为重要：车载/机器人端不可能带着整个离线数据集做适应，WSRL 证明「短暂预热 + 纯在线」可行——这就是 TTT 系统启动时的推荐流程（先影子模式收集少量数据校准，再开启适应）。
