# In-Context Imitation Learning via Next-Token Prediction (ICRT)

- **arXiv**: [2408.15980](https://arxiv.org/abs/2408.15980) | **发表**: arXiv 2024 | **团队**: Letian Fu 等（UC Berkeley）
- **PDF**: [英文原文](../papers/pdf/ICRT_2408.15980.pdf) · [中文翻译](../papers/zh/ICRT_2408.15980_zh.pdf)
- **分类**: 免梯度上下文适应

## 一句话

机器人版「in-context learning」：把传感运动轨迹当 token 流，In-Context Robot Transformer 以人遥操的原始演示轨迹为 prompt，零梯度、零微调地在新任务上继续「续写」出动作。

## 方法

1. **轨迹即语言**：观测-本体-动作序列统一 token 化，next-token 预测目标训练。
2. **Prompt = 演示**：部署时把新任务的 1-3 条遥操演示直接拼进上下文，模型在环境反馈中自回归出动作。
3. **多任务数据格式**：训练时把同任务的多条轨迹串接，塑造「从前文轨迹推断任务」的能力。

## 对机器人 TTT 的意义

免梯度适应在操作域的直接证据（Algorithm Distillation 思想的机器人实例化）：适应能力被预训练进权重，测试时只消耗上下文。与梯度 TTT 的关系是互补而非竞争——上下文适应快但上限受预训练分布约束；RoboTTT 的快权重恰是两者的融合体（上下文以学习的方式被压缩）。

## 局限与注意

- 上下文长度限制演示条数与轨迹长度；分布外任务（新动词/新约束）无法通过 prompt 解决。
- 需要「多任务同 prompt 格式」的大规模遥操数据。
