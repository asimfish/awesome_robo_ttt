# Efficient Online Reinforcement Learning with Offline Data (RLPD)

- **arXiv**: [2302.02948](https://arxiv.org/abs/2302.02948) | **发表**: ICML 2023 | **团队**: Philip J. Ball*, Laura Smith*, Ilya Kostrikov, Sergey Levine（Oxford / UC Berkeley）
- **PDF**: [英文原文](../papers/pdf/RLPD_2302.02948.pdf) · [中文翻译](../papers/zh/RLPD_2302.02948_zh.pdf)
- **分类**: TTT 之前的阶段——RL 微调与平滑探索

## 一句话

不做离线预训练、不做约束，只用三个「简单但关键」的设计——离线/在线数据对称采样、LayerNorm 防 critic 外推爆炸、大 critic 集成——off-policy RL 从零在线学习即可把离线数据用得比专门的离线→在线方法更好，D4RL/Adroit/V-D4RL 上 2.5× 提速。

## 方法

1. **对称采样**：每个 batch 一半离线一半在线。
2. **LayerNorm critic**：抑制 Q 值在 OOD 动作上的外推发散。
3. **集成 + 高 UTD**：样本效率。

## 对本仓库 / 方案的意义

离线→在线 RL 的「极简强基线」——任何声称解决 on-policy 早期崩溃的方法都要与它比。其核心洞见「不稳定来自 critic 外推、用归一化而非悲观约束解决」，与我们「不稳定来自探索噪声积分放大、用接口滤波而非保守约束解决」在方法论上对偶：**找到不稳定的物理来源比加约束更有效**。
