# TTRL: Test-Time Reinforcement Learning

- **arXiv**: [2504.16084](https://arxiv.org/abs/2504.16084) | **发表**: NeurIPS 2025 | **团队**: Yuxin Zuo 等（清华 PRIME-RL）
- **PDF**: [英文原文](../papers/pdf/TTRL_2504.16084.pdf) · [中文翻译](../papers/zh/TTRL_2504.16084_zh.pdf)
- **分类**: TTT 新浪潮

## 一句话

在无标签测试数据上做 RL：对每道题采样多个答案，多数投票结果当伪奖励驱动 GRPO 更新——AIME24 pass@1 提升约 159%（v1 报告；会议版报 211%），且能超过初始模型 maj@N 的理论上限。

## 方法

1. **伪奖励 = 自洽性**：同一问题采 N 个回答，多数派答案当「标签」，一致者奖励 1、否则 0。
2. **GRPO 更新**：用组内相对优势做策略梯度，全程无真实标签。
3. **为何能超 maj@N**：RL 更新改变了采样分布本身，后续采样质量整体上移，形成自举。

## 对机器人 TTT 的意义

「测试时 RL」范式的证明：**一致性可以当奖励**。机器人对应物：影子模式/世界模型内对候选行为批量 rollout，用一致性投票 + 规则检查构造伪奖励，夜间批量做「部署间隙 RL」——把测试时 RL 降级为离线执行以绕开延迟与安全约束。TT-VLA 是它在操作域的直系后继。

## 局限与注意

- 依赖基座先验足够好：多数派本身错误时会自我强化（确认偏误的 RL 版）。
- 需要大量并行 rollout，实时闭环控制无法直接使用。
