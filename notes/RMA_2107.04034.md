# RMA: Rapid Motor Adaptation for Legged Robots

- **arXiv**: [2107.04034](https://arxiv.org/abs/2107.04034) | **发表**: RSS 2021 | **团队**: Ashish Kumar 等（UC Berkeley / CMU / FAIR）
- **PDF**: [英文原文](../papers/pdf/RMA_2107.04034.pdf) · [中文翻译](../papers/zh/RMA_2107.04034_zh.pdf)
- **分类**: 部署时策略适应（免梯度对照）

## 一句话

不更新任何权重的「适应」：adaptation module 从最近的状态-动作历史**前馈**推断环境隐变量 z（负载、摩擦、地形），喂给固定的 base policy——亚秒级适应，四足真机爬坡、踩油污、负重全通过。

## 方法

1. **Phase 1**：仿真中用特权环境参数 e 训练 base policy π(a|s, z)，z = μ(e) 为环境嵌入。
2. **Phase 2**：训练 adaptation module φ：只看 (s, a) 历史回归 ẑ ≈ z（监督蒸馏）——部署时无需特权信息。
3. **部署**：φ 与 π 均冻结，ẑ 随历史滑动更新，毫秒级前向。

## 对机器人 TTT 的意义

「免梯度适应」路线的代表，是所有权重级 TTT 的必选对照基线：实时性最好（前馈）、零崩溃风险（无梯度）、零审计负担（权重不变）。局限也内生：适应能力被预训练时见过的环境分布封顶，真正的 OOD 漂移（新故障模式）处理不了——这恰是梯度 TTT 的生态位。系统设计的常见组合：RMA 式前馈管毫秒级快反应，梯度 TTT 管分钟级慢漂移。

## 局限与注意

- z 空间覆盖 = 域随机化范围；出范围即失效。
- 需要仿真特权信息做两阶段训练。
