# IDQL: Implicit Q-Learning as an Actor-Critic Method with Diffusion Policies

- **arXiv**: [2304.10573](https://arxiv.org/abs/2304.10573) | **发表**: arXiv 2023 | **团队**: Philippe Hansen-Estruch 等（UC Berkeley，Levine 组）
- **PDF**: [英文原文](../papers/pdf/IDQL_2304.10573.pdf) · [中文翻译](../papers/zh/IDQL_2304.10573_zh.pdf)
- **分类**: 免权重 test-time steering（采样 + critic 重排）

## 一句话

扩散行为策略采 N 个动作，用 IQL critic 计算的权重做重要性重采样——「best-of-N + Q 重排」的理论化范本，且 critic 只在数据集动作上训练、天然抗 OOD 高估。

## 方法

1. **重新解读 IQL**：证明 IQL 的 expectile 回归隐式定义了一个最优策略，该策略 = 行为策略 × 权重函数。
2. **扩散模型当行为策略**：表达力足以覆盖多模态演示分布。
3. **测试时提取**：采 N 个动作 → critic 打分 → 按权重重采样/取 argmax。训练与提取解耦，测试时可调 N 和贪婪度。

## 对机器人 TTT 的意义

给「采样-重排」这个最简单的 steering 提供了理论根基：只要 critic 用 in-sample 学习（expectile/分位数回归），重排就不会被 OOD 高估骗——这是把离线 RL 的保守性智慧移植到 test-time 决策的桥梁。工程上零改造成本：任何 BC 扩散策略 + 任何离线 Q 都能即刻组合。

## 局限与注意

- 上限受行为策略候选覆盖度限制（基座采不出好动作时救不了）。
- N 大时去噪成本线性涨，需配少步蒸馏。
