# 设计空间矩阵：机器人测试时适应方法横向对比（2026-09）

> 对本仓库中最具代表性的 34 个方法按七个维度横向比较。目的：选型时一眼看出「改什么 / 靠什么信号 / 多慢 / 怎么兜底 / 有没有闭环证据」。所有条目均可在 `notes/` 找到精读。

## 维度定义

| 维度 | 含义 | 取值示例 |
|---|---|---|
| **适应对象** | 测试时被改动的量 | 无（前向/搜索）/ 初始噪声 / 潜提示 / 末层 / BN / 编码器 / 快权重层 / LoRA / 全模型 |
| **信号来源** | 驱动适应的监督/目标 | 自监督（重建/IDM/预测）/ 熵·一致性 / 伪奖励 / 任务奖励 / 人类反馈 / 演示上下文 |
| **粒度** | 一次适应覆盖的时间尺度 | 帧级（≤100ms）/ chunk 级（秒）/ 段级（分钟）/ 任务级（小时） |
| **延迟影响** | 对推理延迟的影响 | 恒定（前向内）/ 可异步 / 线性增长 / 阻塞式 |
| **安全机制** | 防崩溃/可回滚手段 | 无 / 重置 / 信任域 / 触发式 / 提案-验证 / 结构性（低层控制兜底） |
| **闭环评测** | 是否在反应式闭环或真机验证 | 真机 / 反应式仿真 / 非反应式（NAVSIM 类）/ 离线 |
| **元训练要求** | 训练期是否需要为适应做准备 | 无 / 辅助头 / 元学习初始化 / TTT 层重训 |

## 读表结论（选型速查）

1. **要恒定延迟又要真学习** → RoboTTT 式 TTT 层（代价：训练期重构骨干）或 DSRL 式噪声策略（代价：需在线 RL）。
2. **不能碰基座、要快上线** → Hydra-MDP 蒸馏 verifier + best-of-N（≈0 延迟），或 ADPro/GPC 类免训练操作。
3. **长时程连续运行** → 必须带重置（RDumb）或遗忘门（Titans）或提案-验证（VANE）；无防护的持续梯度默认视为负收益。
4. **高动态不可重试（驾驶/跑酷）** → 段级「重建再训练」（TTT-Parkour / MPA）+ 帧级前馈兜底（RMA/AnyCar）；帧级梯度慎用。
5. **只有成功数据** → 触发器用 FAIL-Detect 式密度 + 共形阈值；有失败数据 → SAFE 式内部特征头。
6. **闭环证据缺口**：表中「非反应式 NAVSIM」占了驾驶权重级 TTT 的全部——反应式闭环 + 权重级 TTT 仍是空白。
