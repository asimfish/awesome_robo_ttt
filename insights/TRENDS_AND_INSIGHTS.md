# 机器人测试时训练：趋势与洞见（2026-09）

## 九大趋势

### 趋势 1：适应对象持续缩小——「接口化适应」成为主流

适应参数量的演化谱系（按时间与克制程度）：

```
全模型更新 (CoTTA 2022)
  → BN 仿射参数 (TENT 2021)
    → 视觉编码器 (PAD 2021)
      → score decoder (Centaur 2025)
        → 每任务 LoRA (ARC-TTT 2024)
          → 初始噪声 (DSRL 2025)
            → 单个潜提示向量 (TTT-VLA LPO 2026, VANE 2026)
              → 结构化快权重层 (TTT-Layers 2024 → RoboTTT / WAM-TTT 2026)
```

方向明确：**基座冻结 + 显式小接口承载全部可变性**。接口越小，审计面越小、回滚越容易、越不破坏安全认证。2026 年的三个热点接口：latent prompt（容量小但零风险）、初始噪声（与生成模型天然耦合）、TTT 快权重层（容量大且延迟恒定）。

### 趋势 2：可靠性机制从「兜底」升级为「准入」

- 事后补救时代：崩溃了再恢复——SAR 的模型恢复、CoTTA 的随机复原、RDumb 的定期硬重置。
- 事前准入时代（2026）：**VANE 的提案-验证-提交协议**——候选更新在影子副本上隔离评估，用执行后的未来观测验证，有证据才 commit；CVPRW 2026 的拓扑指导 TTA 用持久同调预测「这次适应会不会有益」再决定是否适应。
- 中间形态：触发式适应——Centaur 只在不确定性高的帧触发、VLA-ATTC 的认知离合器、EATA 的样本筛选。

**「什么时候该适应」正在取代「怎么适应」成为核心问题。**

### 趋势 3：System-2 采样/搜索在机器人上爆发，verifier 成为军备焦点

RoboMonkey（CoRL 2025）证明动作误差随采样数呈幂律下降后，一年内涌现完整生态：

| 组件 | 代表工作 |
|---|---|
| 过程奖励模型（PRM）当 verifier | RoVer（+方向引导采样） |
| 推理链与动作联合缩放 | E-TTS（历史缓冲+闭环迭代） |
| 轨迹级 MCTS | SAIL（成功档案+VLM 步级反馈） |
| 相对化 critic | VLA-ATTC（成对比较替代绝对回归） |

verifier 的形态演化：规则模拟（PDM-Closed）→ 蒸馏多头（Hydra-MDP）→ VLM（RoboMonkey）→ PRM+方向（RoVer）→ 相对比较（VLA-ATTC）。

### 趋势 4：算力分配本身成为学习问题

Snell 2024 的 compute-optimal 思想被机器人接住：ELASTIC 用 meta-MDP 学「每个状态该用几步去噪、几个候选」（真机 π0.5 匹配 best-of-10 成功率、省 34% 延迟）；DA-SIP 用难度分类器选步数预算；DIRECT 按场景难度路由模型。**固定超参的 TTS 正在被自适应调度取代**——这与趋势 2 的触发式适应是同一枚硬币。

### 趋势 5：自监督目标从「重建输入」转向「耦合任务」

- 老结论重申：PAD 消融（控制任务 IDM 赢）、TTT++ 理论（SSL-主任务相关性决定收益）。
- 新证据加码：TT-VLA 明确批评「让输入更可预测 ≠ 更好的动作」；TTT-VLA LPO 改用 state grounding（观测→本体状态）；VANE 用「已执行动作的未来视觉后果」；TTRL/TT-VLA 干脆用伪奖励/任务进度。
- **机器人的独特资产**：闭环里有免费的任务耦合信号——跟踪误差、预测-实测残差、任务进度——比视觉重建与控制的相关性高一个量级。

### 趋势 6：人类数据成为测试时的转向信号

WAM-TTT 把「看人类玩」做成 TTT 的自监督源（无标注人类视频→快权重记忆→动作引导）；ITPS 系统化人类交互引导；SAIL 的成功轨迹档案支持检索式上下文。**「部署后学习」的数据来源从自身经验扩展到旁观人类**——跨具身对齐（WAM-TTT 的 meta-training）是解锁钥匙。

### 趋势 7：驾驶域「改权重 vs 冻结搜索」正面对垒

- 改权重派：Centaur（navtest 登顶，但仅开环验证，认证难题未解）。
- 冻结搜索派：TOAD（CEM+冻结 scorer，即插即用 6 个 planner，工业更友好）。
- 感知 TTA 趋于成熟（LearnableBN AAAI 2026、AR-TTA），**规划/决策层的 TTT 是当前前沿**；Post-Training 综述给出坐标系。
- 反应式闭环 + 权重级 TTT 的组合至今无人占坑——仍是开放空间。

### 趋势 8：段级「重建世界再训练」成为高动态场景的现实 TTT 形态

帧级在线梯度在不可重试、高速的场景（驾驶、跑酷）既危险又来不及（BayesMPC）。2025-2026 出现第三条路：**测试时重建当前环境 → 在仿真里快速微调 → 零样本回到真机**。

- TTT-Parkour：RGB-D 前馈重建地形网格，人形策略在仿真上微调，捕获-重建-训练-部署 <10 分钟；
- MPA：3DGS 重建驾驶场景生成反事实数据，训练 adapter + Q 模型后推理时择优；
- 这与 DayDreamer（2022，在线学习世界模型再在想象中训练）一脉相承——**世界模型/重建器正在成为 TTT 的「训练场」基础设施**，而 DREAM-Chunk 把世界模型用作 chunk 内的测试时匹配器。

时间粒度谱系由此补齐：帧级（TTT 层 / 异步梯度）→ chunk 级（DREAM-Chunk / DCDP）→ **段级（分钟，重建再训练）** → 任务级（每任务 LoRA，小时）。

### 趋势 9：失败检测器成为适应系统的标配前置件

「什么时候该适应」的答案正被独立成一个子领域：

| 方法 | 需要失败数据？ | 信号 | 保证 |
|---|---|---|---|
| Sentinel (CoRL 2024) | 否 | 动作块分布时间一致性 + VLM 进展 | 分工检测两类失败 |
| FAIL-Detect (RSS 2025) | **否** | 成功分布密度（流模型）等标量 | 共形预测动态阈值 |
| SAFE (NeurIPS 2025) | 是（可跨任务泛化） | VLA 内部特征 → 失败似然 | 共形预测 |

三者共同点：**信号来自策略内部**（动作分布、隐层特征），而非外挂感知；且都引入共形预测给阈值以统计保证——回应了 TTA 领域「阈值手调」的老问题。结合 Centaur 的 Cluster Entropy、VLA-ATTC 的认知离合器，「检测 → 触发适应/回退 → 验证 → 提交」的完整闭环（趋势 2）已具备全部零件。Sentinel 的提醒尤其重要：熵类信号抓不到「自信地做错」，触发器必须分层。

## 五条核心洞见

### 洞见 A：「安全 TTT」的事实标准正在成形

三个独立工作从不同角度收敛到同一设计模式：

> **冻结基座 + 小可变接口 + 验证式提交 + 一键回滚**

- RoboTTT：更新规则本身是训练期验证过的网络组件（快权重层）；
- DSRL：增量沉淀在噪声策略，回退 N(0,I) 即恢复 BC 行为；
- VANE：影子提案 + 未来证据验证 + 可逆提交。

这四要素可作为任何机器人 TTT 系统的设计检查清单。

### 洞见 B：三时间尺度分工是部署适应的正确架构

单一机制包打天下已被证伪（BayesMPC：失稳时间常数快于梯度收敛；RDumb：长时程梯度必崩）：

| 时间尺度 | 机制 | 代表 |
|---|---|---|
| 毫秒级（突变） | 前馈推断，零梯度 | RMA、Algorithm Distillation |
| 秒-分钟级（决策困难） | 采样/搜索/verifier | RoboMonkey、E-TTS、TOAD |
| chunk 内（随机扰动） | 世界模型匹配 / 特征修正 | DREAM-Chunk、DCDP |
| 分钟级（新环境几何） | 重建 + 仿真微调 | TTT-Parkour、MPA |
| 分钟-小时级（慢漂移） | 梯度 TTT（带防护） | Centaur、TTT 层、Continual-MAML |

外加一条：还来得及的时候**主动采集信息**（BayesMPC），比事后适应便宜。

### 洞见 C：verifier 质量是所有测试时方法共同的天花板

三个独立证据链指向同一瓶颈：TOAD（fixed-vocab scorer 出分布即崩，搜索反而降分）、TTRL（多数派错误时自我强化）、Hydra-MDP 消融（蒸总分不如蒸子指标——标量分数有信息瓶颈）。推论：**研究布局应「验证者优先」**——先把 verifier 的 OOD 鲁棒性做扎实（扰动轨迹训练、解耦设计、ensemble+保守下界、相对比较），再谈 steering/TTT 的收益。

### 洞见 D：元训练是 TTT 的隐形前提

从 MOLe（2018：不做 meta-training，在线 SGD 无效）到 TTT-E2E（2025：外环优化「TTT 之后的损失」）到 WAM-TTT（2026：meta-training 对齐人-机空间），八年证据一致：**部署时才加 TTT 注定失败，训练管线必须为适应做准备**。计划采用 TTT 的团队应在预训练/微调阶段就预埋：辅助头联合训练（PAD）、元学习初始化（MAML 式）、或直接用 TTT 层重构骨干。

### 洞见 E：分层控制架构是 TTT 的天然安全垫（与本仓库源头工作的连接）

TTT 的更新噪声最终要经过执行链路。若策略输出高阶量（加速度/速度目标）、底层由经典控制器（PID/MPC）跟踪，则上游适应引起的扰动会被低层滤波与限幅——结构性地限制单步伤害。证据同构：Neural-Fly 只适应末层增益（PID 兜底）、Centaur 的 TTT 在规划头（控制栈兜底）、DSRL 的噪声接口（BC 流形兜底）。这是把「TTT 装进安全壳」最便宜的一层，也是本仓库源头实验（CADI：导数动作空间 + 低层跟踪）正在验证的命题。

## 开放问题（论文机会）

1. **反应式闭环 + 权重级 TTT**：Centaur 停在非反应式 NAVSIM，真正的闭环（CARLA/HUGSIM/真车影子模式）无人完成。
2. **长时程部署的适应增益衰减曲线**：RDumb 的 CCC 只测了感知；机器人/驾驶闭环的数十万步连续漂移评测协议空缺。
3. **TTT 层的训练成本工程**：语言域已有解（LaCT 大块更新、TNT 分层记忆+两阶段、Titans 遗忘门），控制域的对应配方（一个 episode 作为一个 chunk？局部记忆按 chunk 重置？）待建立。
4. **verifier 的 OOD 鲁棒性基准**：TOAD 揭示的问题没有标准评测——「scorer 用于搜索时的可靠性」值得一个专门 benchmark。
5. **安全认证框架**：ISO 26262/SOTIF 语境下「验证过的更新规则」（TTT 层）vs「运行时权重漂移」（裸梯度）的形式化论证，学术空白。
6. **探索噪声频谱与适应噪声频谱的统一理论**：Pink Noise / gSDE / Q-Chunking 说明训练期探索的最优时间相关性存在（β≈1）；测试时更新引入的「适应噪声」是否有同样的最优频谱、能否由低层接口（积分链 + 跟踪控制器）自动整形——尚无人研究，正是本仓库源头方案的切入点。
