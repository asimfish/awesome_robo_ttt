# 从文献到方案：CADI × TTT 研究路线图（2026-09）

> **2026-09-02 更新**：完整方案已升级为 [`proposal/CADI_TTT_PROPOSAL_v2.md`](../proposal/CADI_TTT_PROPOSAL_v2.md)。七臂实验全部完成：匹配噪声预算（σ=0.03）下 E4（泄漏接口）95.0% ≈ E5（原版）93.0% ≈ E1 92.0%（单 seed）——8/26 预注册的滤波器等价性判据触发，「接口提升 RL 微调成功率」主张在准静态任务上不成立；被证实的是「积分接口把探索噪声染红」的机理。v2 据此把接口重新定位为**部署期适应的结构性安全壳**，以 TTT 为主线。本文保留为决策清单。

> 本文把仓库 88 篇文献的结论落到我们自己的研究方案上：以「高阶导数动作接口 + 低层跟踪控制」（CADI，源自 s2drive_proposal/embodied 实验线）为底座，规划测试时训练的差异化研究路径。

## 一、方案回顾

我们的管线：**DP 模仿初始化 → 离线 RL → on-policy 在线 RL → 部署期 TTT**。核心架构选择是把策略的动作空间重参数化为高阶导数量（加速度/增量指令），由低层控制器（PID 类）跟踪执行。已有实验证据（robomimic Square 任务）：

- 导数接口需要**闭环重标注**（开环差分会积分漂移）与 **cmd 可观测化**（obs_cmd），否则 BC 先验失效；
- 纯积分器接口会把探索噪声积成无界随机游走（Arm C 崩溃），**低噪声（E1 恢复至 92%）与泄漏积分器（E3）证实了噪声放大机制**——低层接口对上游噪声的滤波特性是双刃剑，需要显式设计。

## 二、文献坐标下的定位

按本仓库分类学，我们的方案落在 **④ 权重级 TTT** 与 **⑤ 免权重 steering** 的交界处，且带有三个文献中稀缺的属性：

| 属性 | 文献现状 | 我们的位置 |
|---|---|---|
| 反应式闭环 + RL 训练的策略 + 权重级 TTT | 无人占坑（Centaur 仅开环；RoboTTT 是 BC 系） | 直接可占（robomimic/CARLA 反应式闭环） |
| TTT 更新噪声的结构性滤波 | 只有间接同构证据（Neural-Fly 末层、DSRL 噪声接口） | **导数接口 + 低层跟踪 = 显式低通滤波器**，可形式化论证 |
| 免费的任务耦合自监督信号 | 趋势⑤呼吁但少有实现 | **跟踪误差 / 预测-实测加速度残差**天然存在于闭环 |

## 三、从 61 篇提炼的设计决策

1. **TTT 形态**：首选 TTT-layer/快权重路线（RoboTTT 证明 30Hz 可行、延迟恒定、更新规则可预验证）；裸梯度只做异步触发式对照（Centaur 配方：单步 + 缓冲平均 + 不确定性触发）。
2. **自监督目标**：主信号用**动力学一致性**（预测加速度 vs 实测加速度残差、PID 跟踪误差）——PAD 消融与 TTT++ 理论支持控制任务上动力学类目标最优；辅信号用决策置信度（DP 多候选的聚类熵，Centaur 已验证于规划）。避免纯重建（TT-VLA 警告）。
3. **训练期预埋**：在线 RL 末期加元学习外环，优化「TTT 更新之后」的策略损失（TTT-E2E 配方：只更 MLP、内环 mini-batch）；否则部署期梯度与训练目标错配（洞见 D）。
4. **安全壳四件套**：冻结感知与低层控制，适应只作用于「DP 之后、控制器之前」的低维接口（Neural-Fly 位置）+ Fisher 信任域（EATA）+ 定期重置（RDumb 默认开）+ 不确定性触发与回滚（Centaur/VANE 式提案-验证-提交）。
5. **免权重对照组**：DSRL 噪声空间 RL 是我们最强的「不改权重」对照（同样吃我们的低维动作接口红利：噪声空间维度 = 导数 chunk 维度，小）；best-of-N + 蒸馏 verifier（Hydra-MDP 式多头）做第二对照。
6. **verifier 计划**：候选加速度 chunk 过运动学 rollout 打分（PDM 结构：硬门 × 软分），**「PID 可跟踪性」作为文献中没人做过的 verifier 头**（超执行器带宽的候选降权）；scorer 训练吸收 GTRS 的词表 dropout 防 OOD 崩溃。
7. **评测协议**：反应式闭环（robomimic 扰动版 / CARLA）+ 长时程漂移流（RDumb/AR-TTA 教训：报告适应增益随时间的衰减曲线与崩溃统计）+ 同延迟预算下「权重级 TTT vs DSRL vs best-of-N」的 Pareto 对比（TOAD/综述都没系统做过）。

## 三-B、第三批文献带来的新决策（2026-09 增补）

8. **理论支撑段有了现成坐标**：Pink Noise（ICLR 2023）证明连续控制探索噪声的最优功率谱在 β≈1（粉噪）；我们的接口是一个积分链——白噪经一次积分变红噪（β+2，Arm C 的无界游走），泄漏积分把颜色拉回中间（E3）。**泄漏系数 = 噪声颜色旋钮**，可以把「最优泄漏系数」的搜索写成对 Pink Noise 结论的验证，并与 gSDE（生成端平滑）、Q-Chunking（分块相关性）三方对照。
9. **RL 阶段的稳定性要双管齐下**：Cal-QL 说明「先崩再涨」来自 Q 尺度失配（价值侧），我们说明来自探索噪声放大（动作侧）；两者正交——实验里应加 Cal-QL/WSRL 式价值校准做对照，把动作侧贡献剥离干净。RLPD 是必须放进表格的极简基线。
10. **分块 × 导数接口可叠加**：Q-Chunking 证明分块动作空间上的 RL 探索更有效、n 步回传更稳。我们的导数 chunk 天然是分块的——应显式引用并做「分块长度 × 泄漏系数」的二维消融。
11. **触发器直接用现成件**：TTT 的开关不必自己发明——FAIL-Detect（只用成功数据 + 共形阈值）适合我们数据现状；Sentinel 的动作分布一致性可零成本复用 DP 的多候选输出；后期有失败数据再上 SAFE 式内部特征头。
12. **在线阶段的启动流程照 WSRL**：部署 TTT 前用少量影子 rollout 预热价值/统计量再开启更新，避免分布切换时的崩塌。
13. **TTT 层路线的训练成本预算按 LaCT/TNT 估**：若走快权重层，采用大块更新（一个 episode 一个 chunk）+ 局部记忆按 chunk 重置的 TNT 结构，训练成本可控在 Titans 小块的 1/10 量级。
14. **残差接口是备胎**：若导数接口在某些任务上 BC 先验难对齐（我们在 Square 上已遇到需 obs_cmd 的问题），ORPA 式「冻结基座 + 关节空间残差模块」是同构的退路，适应量同样受限幅保护。

## 四、论文的差异化主张（草案）

**核心主张**：分层动作接口（高阶导数 + 低层跟踪）是部署期适应的结构性使能器——
(a) 它把 TTT 的更新扰动经积分链和跟踪控制器低通滤波，给出可形式化的单步伤害上界（把 Arm C/E1/E3 的噪声放大-抑制实验从「RL 探索」平移到「TTT 更新」维度）；
(b) 它天然产出高任务相关性的自监督信号（跟踪残差），解决 TTT 目标错配问题；
(c) 它使免权重路线（DSRL/重排）与权重路线共享同一个低维接口，第一次能在同一系统内公平对比两族方法。

**风险与预案**：
- 若 TTT 层训练不稳（TBPTT 成本），退到 Centaur 式异步裸梯度 + 我们的结构性滤波论证，故事仍成立；
- 若动力学一致性目标增益小，用失败数据训 Q_risk 门控（Recovery RL）转向「安全约束下的适应」叙事；
- BayesMPC 边界要正面引用：明确我们的 TTT 针对慢漂移，快突变由低层控制器与前馈兜底。

## 六、P0 之后的第一个适应实验（P1'，已具体化，待执行）

P0b 显示接口在执行器增益漂移下零适应即占优，这给了一个最干净的首个 TTT 测试床：

- **信号**：跟踪残差 $r_t$ —— 用 `psd_E4_det` 的无漂移 rollout 回归「执行指令 $c_t$ → 末端位移 $\Delta x_{t+1}$」得到名义映射 $\hat{K}$（需从 `normalization.npz` 反归一化 eef_pos）；部署期用滑窗最小二乘在线估计增益比 $\hat g_t = \langle \Delta x, \hat K c\rangle / \|\hat K c\|^2$。
- **适应对象（TTT-I 最小版）**：接口参数 $s_{\text{eff}} = s/\hat g_t$（裁到 [0.5, 2]），λ 不动 —— 这是 Neural-Fly 式「末端低维增益适应」，P2 的界直接适用。
- **公平对照（关键）**：对原版 E5 施加同样的输出增益补偿 $u \leftarrow u/\hat g_t$。接口的结构性价值 = 两者都补偿之后仍剩下的差距；若差距归零 → 接口在增益漂移上的收益只是「更容易估计 $\hat g$」（仍是结果，但主张要降级）。
- **漂移**：增益 ×{0.8, 0.7}、延迟 {2, 3}（残差法对延迟应无效——这是 P4 专一性的一个负控制）。
- **指标**：成功率恢复曲线（按 episode）、$\hat g_t$ 收敛时间、执行 jerk/最大单步变化在适应期间的峰值（vs P2 界）。
- **实现**：在 `DriftWrapper` 与 `DerivativeActionWrapper` 之间加 `AdaptiveGainWrapper`（含残差估计器）；rollout 脚本加 `--adapt {none,interface,raw}`；每格 100 episodes × 3 评测 seed。预计 1 天。
- **之后**：神经版 TTT-I（更新接口头 θ_a 的逐维仿射）与 PAD 式编码器 IDM 更新（M1）进入 P2 主对比。
